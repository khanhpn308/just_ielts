# Source registry

Maintain source provenance separately from learning notes. For each source record: `source_id`, title, author/publisher, edition/year, URL or local reference, license/redistribution permission, unit/page/section, and date checked.

**Do not upload unlicensed book PDFs, commercial question banks or transcribed audio** into this public repository. Keep local-only material in `private/` or `sources/raw/` (both gitignored). A reference to a source is not proof that the agent inspected that source.
