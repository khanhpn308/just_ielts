# Principles and strategies

- [INDEX.md](INDEX.md): **compact machine/human retrieval index**, generated from YAML frontmatter.
- [general/](general/README.md): cross-skill principles. The existing [eight golden principles](general/8_golden_principles) are intentionally preserved.
- [reading/](reading/README.md): core reading principles + question-type strategies.
- [listening/](listening/README.md): listening core + part-specific skills.
- [writing/](writing/README.md): Writing Tasks 1 and 2.
- [speaking/](speaking/README.md): Speaking Parts 1–3.

**Distinction:** principle = invariant reasoning rule; strategy = question-type method; workflow = sequence of study/marking actions.

To add an atomic file, copy `../templates/principle.md`, choose a stable ID and specific `triggers`, then run `python scripts/build_principles_index.py`. Avoid duplicating the entire general guide into each file.

File status vocabulary: `draft` (needs review), `reviewed` (reviewed for pedagogical clarity), `verified` (checked against referenced sources). Status is not an IELTS certification.
