# Learning progress

- `sessions/`: date, skill, duration, material ID, result and follow-up.
- `errors/`: error type, attempted answer, verified answer, evidence, cause, linked principle ID, retest result.
- `reviews/`: periodic progress analysis, strengths, bottlenecks, next priorities.
- `templates/`: copyable session/error/weekly review forms.

**Privacy:** This GitHub repo is public. If a log contains personal or sensitive data, store it under the ignored `private/` directory or make the repository private. The tracked `progress/` folders are suitable only for information you are willing to publish. Do not log fabricated attempts.

Make the difference explicit between **first attempts on unseen material** and **retries on known material**.
